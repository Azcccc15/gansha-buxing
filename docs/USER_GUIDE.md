# 干啥不行目标规划管理软件

版本 V1.0

## 软件用途

干啥不行用于把个人想实现的目标拆成行动，并记录完成情况。用户可以设立学习、阅读、创作、生活技能、习惯培养等不同领域的目标。软件根据目标和期限请求 DeepSeek 提出方案，用户检查并明确确认后才保存到目标列表。用户不需要自行编写阶段、任务或成果标准。

软件包含安卓安装版和电脑开发预览。安卓端直接调用 AI 并使用手机通知，电脑端通过本机服务调用 AI。两端的记录各自保存在当前设备，不自动同步。本说明以安卓安装版为主。AI 输出属于建议，不能保证减重、收入、考试等现实结果；目标不合理或不适合制定方案时，会说明原因或建议缩小范围。

## 安装与首次进入

安卓安装版要求 Android 8.0 或更新版本，并使用更新的 Android System WebView。将正式签名的 APK 传到手机，使用系统安装界面完成安装。若系统询问是否允许该来源安装应用，用户应根据安装包来源自行决定。安装包不包含用户密钥，也不会自动建立账户。

首次打开进入“今日行动”。顶部导航分为“今日行动”“我的目标”“＋ 新目标”和“设置”。尚无目标时显示设立目标入口。导航切换不会删除记录。电脑预览需要运行本机 Node 服务，并打开本机页面；安卓安装版日常使用无需保持电脑运行。

目标和记录保存在当前设备。手机卸载或清除数据、浏览器清理站点数据都会移除对应记录。关闭软件不会主动清除记录。建议使用导出功能留存自己的资料，V1.0 暂不支持从导出文件导入恢复，也没有云端账户恢复功能。

## 配置 AI 连接

点击“设置”，找到“DeepSeek 接口设置”，把自己在 DeepSeek 平台取得的 API 密钥粘贴到密钥框。输入框使用密码显示方式，不展示旧密钥。模型名称已有默认值；更换时需填写账户实际可用的模型，软件不能保证任意模型名称可用。

“测试连接”检查当前输入或已保存的密钥和模型，不生成目标方案，也不会自动保存新输入。测试通过后仍需点击“保存设置”，新配置才用于后续分析。保存成功会清空输入框，旧密钥不会重新出现。输入框留空保存会保留原密钥，输入新值保存则替换旧值。

安卓端使用 Android Keystore 保护加密密钥；电脑端将密钥保存在本机服务配置文件中。用户不要把密钥写进目标、公开截图、反馈或上传仓库的文件。设置显示已配置，只表示已有配置，不代表账户余额、模型权限和网络始终可用。

如果密钥失效、额度不足、网络中断或模型不可用，分析仍可能失败，界面会提示相应问题。修正后可以重新提交。软件不会因一次失败而连续自动发出付费重试。AI 调用使用用户自己账户的额度，软件不代替用户购买额度。

## 创建目标

点击“＋ 新目标”，在目标框描述想完成的事，例如读完一本书、练习一种技能或完成创作。最好表达可观察的成果，而不只是“变优秀”。不需要自己列出任务和阶段。避免填写无关的身份证号、银行卡号、账户密码或他人的隐私。

在计划周期中填写天数，范围为一至三千六百五十天。每天可用分钟数可以留空，留空时由 AI 提出建议并列为假设。软件不要求先填写复杂个人资料表。点击生成后显示正在分析，并可取消本次分析。

分析会把目标、期限、可用时间和必要的问卷回答发送给 DeepSeek。取消请求不会保存目标或创建行动。请求失败时界面显示失败信息，不使用本地假方案掩盖错误。用户可以保留目标文本，检查连接后手动重试。

## 点选补充问卷

可以合理规划时，AI 尽量直接给出草案。只有关键信息缺失时才提供一轮简短问卷，优先一道题，必要时最多三道。每次只展示一道题，用户点击“是”或“否”作答，不需要再输入长段文字。

点击答案后前进到下一题，顶部显示题号与进度。可以返回上一题，已经选择的答案会保持选中。题目只询问一个明确事实；年龄、体重等精确信息不会从是非答案中凭空推断。用户应按照真实情况回答，不应为了得到计划而随意选择。

答完进入检查页面，逐项显示原题和答案。点击某题的修改入口可以重新选择。确认无误后统一提交这一轮回答，不会每点一个答案就发出一次 AI 请求。提交失败或取消后，已选答案仍保留，方便再次尝试。

一轮问卷后不继续反复追问。信息仍不足时，AI 可以缩小建议范围、说明必要假设或说明暂时无法形成合适方案，而不是编造个人情况。涉及健康等领域时，用户仍应根据实际条件判断方案是否适用。

## 检查与确认方案

行动路线包含标题、总体说明、计划周期、每日时间、成果标准、假设、阶段与近期行动。警示单独列出。用户应检查时间、资源和限制是否合适。阶段覆盖整个周期，具体行动一次最多安排七天；较短目标按实际天数安排。

每项行动有建议时间、预计时长和完成标准。建议时间不代表已经创建系统闹钟；显示草案也不代表已经保存目标。用户可以修改目标后重新分析。确认草案可接受后，点击“确认，开始我的目标”，软件成功写入本机记录后切换到目标列表。

目标开始日按设备当前本地日期安排。存储失败时会显示错误，不把未保存操作显示为成功。软件只在确认后保存目标，日常提醒需要另外开启。即使用户接受草案，AI 也不会替用户在现实中执行行动。

## 今日行动与再次确认

今日行动显示今日完成项数、进行中的目标数、已达成目标数，以及今天和已经到期但未完成的行动。卡片列出日期、时间、预计时长、标题、所属目标和完成标准。未来行动在目标详情中查看，不能提前打卡。

完成现实行动后点击“完成这项行动”，会出现独立确认界面，再次列出标题、标准和记录锁定说明。如果尚未完成，点击“再想想”返回，记录保持未完成。只有再次点击“确认完成”才写入完成时间。

完成后显示鼓励界面。当天安排的行动全部完成时，显示当天行动完成的祝贺。关闭祝贺后，卡片显示完成且锁定，不再提供撤销、删除或重复打卡入口。重新打开软件后，锁定记录仍然保留。

记录锁定是软件的界面操作规则，不构成对设备管理员、系统重置或导出文件的防篡改保证。软件不会自动向第三方证明目标已经实现，也不会把任务完成次数当作现实成果的法律凭证。

## 查看目标和生成后续行动

我的目标展示进行中的目标、已完成行动数量、开始日期、总周期和成果标准。展开阶段与全部行动后，可以查看阶段、未来任务和完成记录。目标周期超过已安排天数时，会显示已安排到第几天，并提供生成后续行动入口。

生成后续行动使用原目标、剩余周期和必要的近期行动摘要。用户再次确认后，软件按原目标对应日期追加新行动，不覆盖已完成记录。每次最多生成七天，直到该周期的行动全部安排完毕。已有完整安排时不再显示这一入口。

后续行动不会在后台无限自动生成，也不会未经确认创建新任务。用户应在已有安排将要结束时按需请求，并检查建议是否适合当前实际情况。后续具体行动不会替换原目标的成果标准。

## 删除行动与结束目标

未完成行动提供删除入口。点击后再次确认，说明只删除这项行动及其对应提醒，其他行动和完成历史会保留。确认删除后才执行；取消则不改变记录。已经完成的行动没有删除入口。

不想继续目标时，可点击结束这个目标。确认后停止剩余行动和提醒，目标进入历史，已完成记录保留。结束目标不会把它标记为成功。用户可另设更合适的目标，不需要通过伪造达成来停止计划。

## 确认达成与成就历史

真实成果达到目标标准后，点击“我已达成目标”。软件再次展示成果标准，并说明打卡次数不能代替现实结果。用户明确确认后，才记录达成时间、停止剩余提醒并显示专门的目标达成祝贺。

达成目标进入成就与历史，展示达成日期和行动记录，首页达成数量随之更新。单项完成、当天行动完成和整个目标达成是三个不同流程；完成所有已生成任务不会自动宣布现实目标已经实现。

## 开启手机提醒

设置中的行动提醒可以开启或关闭。安卓系统需要通知权限时会弹出授权界面；拒绝后仍可使用规划与记录。允许后，软件安排未完成且时间未到的行动通知。系统通知不需要电脑保持运行。

完成或删除行动、结束或达成目标后，会取消对应提醒。关闭提醒则取消当前安排。手机重启、应用更新、系统时间或时区变化后，软件恢复仍未到期的安排。通知显示、声音和勿扰模式仍由系统设置控制。

省电、通知渠道、厂商后台限制和强行停止应用都可能影响送达，不能保证每台手机精确到分钟。软件使用非精确调度，不申请精确闹钟权限。这是日常行动辅助，不作为紧急、医疗或人身安全提醒。

## 日历与记录导出

未完成行动可加入日历。安卓端会打开系统新建事件页面，并填入标题、时间和完成标准，由用户检查并保存。软件不读取已有日历，也不绕过日历确认自动写入。没有日历应用时会提示无法打开。电脑端会导出日历事件文件，由用户自行导入。

设置中可以导出个人记录为 JSON，包含目标、行动、完成和达成状态，不包含 AI 密钥。安卓端使用系统文件保存界面，电脑端由浏览器下载。V1.0 暂不支持回导恢复，导出文件应自行妥善保管，不要公开上传。

## 故障处理与隐私

连接失败时检查网络、密钥、模型与账户额度，再手动重试。分析取消或超时不会自动建目标。若本地记录无法解析，软件提示先导出原始记录，并阻止覆盖写入，不把异常资料静默当作空白记录。

避免在多个浏览器页面同时修改同一份资料。软件监听页面间存储更新，并拒绝发现的过期状态覆盖；提示记录已更新时应刷新后再继续。手机与电脑记录独立，需分别留存。

软件不注册账户，不接入广告或分析统计 SDK。AI 请求只发送必要内容，第三方处理以其协议和隐私政策为准。反馈时提供操作步骤和去除个人信息的截图，不要附带密钥、身份证明或个人记录文件。
