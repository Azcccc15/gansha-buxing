# 隐私说明

适用版本：干啥不行目标规划管理软件 V1.0。

目标、行动、完成记录和成就保存在当前设备。本版本不提供账号、广告、统计 SDK 或跨设备同步。安卓端不启用系统应用数据备份；卸载或清除数据会移除本地记录。导出 JSON 用于个人留存，本版本不支持导入恢复。

只有在你点击目标分析、后续行动生成或测试连接时，软件才会向 DeepSeek 发送相关请求。分析内容包含目标、期限、可用时间、当前问卷回答；后续行动生成附带必要的目标摘要和近期任务状态。请勿填写无关的身份证号、联系方式或第三方隐私。DeepSeek 对请求的处理以其服务协议和隐私政策为准；软件本身不能代表第三方承诺零留存。

安卓端直接通过 HTTPS 连接 DeepSeek，密钥使用 Android Keystore 保护的 AES-GCM 加密保存。电脑开发服务通过服务端调用 DeepSeek，密钥在本机 .env 中保存，不返回浏览器。测试密钥时输入内容不会自动保存，保存时才生效。

开启行动提醒时，安卓系统会请求通知权限。拒绝后仍可使用其他功能。提醒由手机系统调度，不要求读取通讯录、位置、现有日历或全盘文件。加入日历会打开系统事件编辑页面，由你最后确认。导出记录会打开系统文件保存页面，由你选择位置。

AI 生成的是待确认建议，不能自动替你执行目标，也不保证减重、收入、考试等结果。完成记录锁定是软件的操作规则，不构成对设备管理员、系统重置或用户导出文件的防篡改保证。

如需反馈，请通过发布仓库提供的渠道联系项目维护者，不要附带密钥或身份证明。此版本尚未提供运营方云端客服账户或线上个人资料删除接口。
