## 你说目标，它帮你找到第一步

想读完一本书、学一门技能、坚持运动，或者推进一个总在拖延的个人项目？

**干啥不行**是一款安卓个人目标规划与行动记录软件。输入“想做什么”和“准备花多久”，DeepSeek 会帮你生成阶段方案、成果标准和每日行动。你检查并同意方案后，再开始执行。

需要了解你的情况时，优先问一道可以直接点选“是／否”的问题，一轮最多三道。少填表，少打字，把精力留给真正想做的事。

> 比如输入「30 天读完一本书」：AI 可以先问你是否选好了书，再给出阅读阶段、当天建议和完成标准。你也可以规划学习、运动、生活整理等其他目标，方案会根据你的输入生成。

## 从“我想做”，到“我做到了”

| 你正在经历的事 | 干啥不行可以帮你做什么 |
| --- | --- |
| 有目标，但不知道从哪儿开始 | 生成阶段路线、成果标准与行动建议，让第一步更明确 |
| 填一大堆资料太累 | 用简短的是非题补充必要信息，点选即可回答 |
| 计划写得很满，今天却没动 | 把近期行动放到“今日行动”，按建议时间执行 |
| 总是忘记开始 | 设置本地提醒，或把行动加入系统日历 |
| 做完了，却感觉没有积累 | 二次确认后锁定完成记录，让每一步都有迹可循 |
| 终于实现了自己的目标 | 按成果标准亲自确认达成，获得专属庆祝并保留成就历史 |

你始终掌握决定权：AI 方案需要你确认；未完成的行动可以删除；结束目标时保留已完成的历史。后续行动每次最多生成七天，再由你确认，方便边做边调整。

## 三步开始你的第一个目标

1. **下载并安装**：点击顶部绿色按钮，在安卓手机打开 APK，按系统提示允许本次安装。按钮下载的是安装包，手机仍需自行确认安装；建议保持 Android System WebView 为较新版本。
2. **连接 AI**：打开软件“设置”，填写自己的 DeepSeek API 密钥，保存并测试连接。AI 请求使用你的 DeepSeek 账户额度，是否收费及余额以服务方账户为准。
3. **说出目标，确认开始**：在“＋ 新目标”输入目标与期限，完成必要的点选问答，检查方案后开始行动。

安卓端直接通过 HTTPS 连接 DeepSeek，**不需要电脑一直开着**。目前提供安卓安装包，暂无 iOS 版本或应用商店安装入口。

## 用得明白，也把记录握在自己手里

- 目标与完成记录保存在当前设备，暂不提供云同步。
- 安卓密钥使用 Android Keystore 加密保存，安装包不附赠或内置任何人的 API 密钥。
- AI 分析所需的目标与回答会发送给 DeepSeek；具体数据流见[隐私说明](docs/PRIVACY.md)。
- 支持导出 JSON 留存，暂不支持导入恢复。卸载或清除应用数据会移除本机记录，请先导出需要保留的内容。
- 完成记录在软件界面内锁定，不能撤销，确认前请检查。

**体验版进度**：已完成自动检查、安卓构建与签名校验；尚未完成真机安装、通知、日历等设备兼容性验收。提醒受通知权限、系统省电和强行停止应用等因素影响，不能当作必须准点触发的闹钟。AI 提供规划参考，具体安排请结合实际情况调整，不承诺健康、收入或考试结果。详见[验证记录](docs/VERIFICATION.md)。

### 电脑开发预览

需要 Node.js 22 或更新版本，无需安装服务端依赖。双击“启动接口.cmd”，打开 http://localhost:8787 ，在设置中填写本机密钥。调试页面位于 `/developer`。浏览器与手机的记录分别保存在各自设备。

```sh
cd api
node src/server.mjs
```

检查接口与记录逻辑：

```sh
cd api
node --test
```

### 安卓构建

用 Android Studio 打开 `android` 文件夹，或在 JDK 17、SDK 35 环境下运行：

```sh
cd android
./gradlew assembleDebug lintDebug testDebugUnitTest
```

Windows 使用 `gradlew.bat`。正式签名配置见 `android/signing.properties.example`；不上传真实配置或签名文件。未配置签名时 release 产物未签名；CI 提供的调试包与 Releases 中的正式签名体验包不同。

本机工具准备、Windows 中文路径构建和发布步骤见[发布说明](docs/RELEASE.md)。辅助脚本使用 PowerShell 7、Python 3.9+。构建从 `api/public` 和 `api/src/system-prompt.txt` 同步资源，请修改源文件。

```text
api/public/       共用界面与目标记录逻辑
api/src/          电脑开发服务、DeepSeek 接口和结构校验
api/test/         接口与数据规则检查
android/          安卓壳、密钥、网络和系统联动
docs/             使用说明、接口、隐私和发布说明
tools/            构建、检查和材料整理
```

交付生成文件、个人申请材料、真实配置与签名均不进入仓库。

更多资料：[架构](docs/ARCHITECTURE.md) · [API](docs/API.md) · [安全反馈](SECURITY.md)
